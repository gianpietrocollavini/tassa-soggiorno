# Tassa di soggiorno

App web (installabile, funziona offline) per registrare i soggiorni e calcolare l'imposta di soggiorno,
con Modello 21 per il Comune e riepilogo trimestrale per l'Agenzia delle Entrate.

## 👉 [Apri l'app](https://gianpietrocollavini.github.io/tassa-soggiorno/)

https://gianpietrocollavini.github.io/tassa-soggiorno/ — funziona su iPhone, iPad, Android, Windows e Mac.

I dati restano sul dispositivo (memoria del browser): online c'è solo l'app vuota.
Istruzioni in [LEGGIMI.txt](LEGGIMI.txt).
